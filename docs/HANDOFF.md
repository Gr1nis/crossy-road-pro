## 4. 💻 Инструкция по запуску сессии на ПК

1. **Синхронизация кода**:
   ```bash
   git pull origin master
   ```
2. **Запуск Blockbench с MCP**:
   - Откройте Blockbench.
   - Убедитесь, что плагин `blockbench_mcp.js` загружен (`File ▸ Plugins ▸ Load Plugin from File`).
   - Запустите сервер: кнопка **Start** в панели **MCP Copilot** (порт `8787`).
3. **Старт в Antigravity на ПК**:
   - Откройте проект в Antigravity на ПК.
   - Скопируйте и отправьте агенту **Мастер-Промпт** из [docs/BLOCKBENCH_MCP_PC_GUIDE.md](file:///Users/egorbelogubec/Downloads/GitHub/Crossy%20road%20pro/docs/BLOCKBENCH_MCP_PC_GUIDE.md).
   - Агент вызовет `get_status`, подтвердит подключение к Blockbench и будет готов моделировать следующего персонажа!
